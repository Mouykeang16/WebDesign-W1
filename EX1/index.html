My First Steps in Web Development

Welcome to my first blog post! I'm a second-year student, and this year I started learning how websites are built. At first, I thought coding was only for people who were already good at computers, but I quickly found out that anyone can start with the basics and improve a little every day.

So far, I have learned that HTML is the skeleton of every web page. It gives structure to the content, like headings, paragraphs, images, and links. Then CSS comes in to make everything look good, with colors, fonts, and layouts. Learning both together feels like building a house and then decorating it.
